2. Datos que se recolectan

La aplicación no solicita ni requiere datos personales: no tiene registro de usuarios, inicio de sesión, formularios de contacto, cookies de seguimiento ni herramientas de analítica. El único dato que guarda es el texto de las tareas que la persona escribe voluntariamente y su estado (pendiente o hecha). Se recomienda no escribir en las tareas datos personales sensibles, como contraseñas, datos bancarios o de salud.

3. Finalidad

Los datos se usan únicamente para mostrar, completar, filtrar y borrar las tareas dentro de la aplicación. No se utilizan para publicidad, perfiles ni ningún otro fin.

4. Transferencia de datos

Los datos no se venden, comparten ni transfieren a terceros.

5. Medidas de protección

  • Los datos se almacenan en una base de datos MySQL local, accesible solo desde el equipo donde corre la aplicación.
  • La aplicación usa un usuario de base de datos con permisos limitados a lo necesario.
  • Las credenciales se guardan en variables de entorno y no en el código.
  • Las consultas a la base de datos son parametrizadas y los datos recibidos se validan.
  • La comunicación se realiza mediante HTTPS y con encabezados de seguridad HTTP.

6. Derechos de acceso, rectificación, cancelación y oposición

Como no se recolectan datos personales identificables, no hay información de este tipo que consultar. Si la persona escribió datos personales dentro de una tarea, puede editarla o borrarla en cualquier momento desde la aplicación, o solicitar su eliminación al correo indicado.

7. Cambios a este aviso

Este aviso puede actualizarse. La versión vigente siempre estará disponible en esta dirección.
